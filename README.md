Connect your SofaBaton X2 or X1S hub directly to Homey over your local network — no MQTT broker required, no cloud dependency. Bind remote buttons to Homey device actions and Flows, create virtual callback devices on the hub, and use the SofaBaton mobile app and Homey simultaneously — a built-in proxy keeps the hub connection in Homey while forwarding traffic from the mobile app. A proxy release function is also available for when the mobile app needs direct hub access, such as initial setup or firmware updates.

The app communicates using the hub's native binary protocol over LAN. An MQTT broker is optional and only needed for the activity-changed Flow trigger. X1S support is included — it shares the X2 binary protocol — but is currently untested due to hardware availability. This app builds on protocol research from the open-source home-assistant-sofabaton-x1s project by m3tac0de.
